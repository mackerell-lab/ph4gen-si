# ph4gen-si
Supporting Information for ph4gen paper

* dirs: training/validation dirs: contain respective systems data
* ph4gen.py is the tool for generating pharmacophores from SILCS-Pharm output.
* analysis.py is the script to produce the results and figures.
* ph4gen-env.yml is a conda env yml file which can be used to create conda env with ```conda create --file ph4gen-env.yml```
